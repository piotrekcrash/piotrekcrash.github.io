Privacy Policy for Rclone

Effective Date: October 12, 2026

This Privacy Policy explains how Rclone ("the Application", "we", "our") accesses, collects, uses, handles, and discloses user information when interacting with Google APIs and Google Drive services.

1. Exact Google API Scopes Requested

The Application requests the following Google OAuth 2.0 scopes strictly to provide backup and synchronization capabilities requested by the end user:

  • https://www.googleapis.com/auth/drive (or https://www.googleapis.com/auth/drive.file): Used solely to read, write, copy, and organize files in your Google Drive as requested via command-line operations.

2. Data Collection and Usage

Rclone is a command-line tool designed for direct interaction with cloud storage. We adhere to the following principles regarding user data:

  • No Telemetry or Analytic Tracking: The Application does not collect, log, or track user browsing behavior, IP addresses, or personal identity markers.
  • OAuth Authentication Data: When authenticating, the Application receives an OAuth access token and refresh token. These tokens are used exclusively to sign API requests to Google servers on behalf of the user.
  • Google Drive Files & Metadata: The Application accesses your Google Drive files, directory structure, and metadata exclusively to execute synchronization and backup operations directed by you.

3. Data Storage, Transmission, and Security

  • Local Storage Only: All OAuth tokens and configuration profiles are stored entirely on the local device or host running the Application.
  • Direct Connection: All data transfers occur directly between the user's host machine and Google's official API endpoints over secure HTTPS/TLS encryption.
  • No Third-Party Servers: We do not operate any external cloud servers, intermediate proxy servers, or third-party databases. No file content or authentication tokens are ever transferred to us or any unauthorized third party.

4. Data Sharing, Disclosure, and Sale

  • No Sale of Data: We do not sell, rent, monetize, or lease any user data or Google user data under any circumstances.
  • No Third-Party Sharing: Google user data is never shared with third parties, advertising companies, data brokers, or external analytics providers.
  • No AI/ML Training: Google user data is never used to train, evaluate, or fine-tune general artificial intelligence (AI) or machine learning (ML) models.

5. Google API Services User Data Policy (Limited Use)

Google API Limited Use Disclosure:

Rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. User Control, Revocation, and Data Deletion

Users maintain full ownership and control over their data:

  • You can revoke access to the Application at any time by visiting Google Account Permissions.
  • You can delete all stored tokens and credentials immediately by running rclone config delete [remote_name] or deleting your local configuration file (e.g., rclone.conf).
